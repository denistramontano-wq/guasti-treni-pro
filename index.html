File M7
Come caricare i file M7

Scegli la linea in alto, poi premi "Aggiorna i file M7" e seleziona insieme i tre file .xlsx della linea: feriale, sabato e festivo. I PDF vengono ignorati.

Sul PC: apri la cartella di rete degli M7 della linea (anche dai collegamenti "M7 rete" sul desktop) ed entra in quella con gli M7 più recenti.

Sul telefono: scegli i file da OneDrive o dalla memoria del telefono.

Gli orari restano salvati su questo dispositivo. Quando escono i nuovi M7 ripeti il caricamento: sostituiscono quelli vecchi. Gli orari speciali (manifestazioni, fiere) si caricano con "Evento" e valgono solo per la giornata.

Le fermate senza foglio nell'M7 hanno l'orario stimato, segnato con ~. Orari e conto alla rovescia usano l'ora del dispositivo.

Orari teorici ricavati dai file M7: verifica sempre con la sala operativa
